Trial Manager for Hostinger Shared Hosting

Install:
1. Upload trial-manager-hostinger.zip to public_html.
2. Extract it in public_html.
3. Open https://your-domain.com/install.php.
4. Enter MySQL database credentials and default admin details.
5. Login at /login.php.

No framework, package manager, SSH, or terminal commands are required.

Important:
- Delete or rename install.php after installation.
- Configure Telegram webhook URL as https://your-domain.com/telegram-webhook.php.
- Configure WhatsApp webhook URL as https://your-domain.com/whatsapp-webhook.php.
- Store WhatsApp Cloud API and Telegram Bot credentials in Settings -> Integrations.
