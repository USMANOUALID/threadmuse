# Trial Manager Deployment Guide

This guide deploys Trial Manager on a production VPS with PHP, MySQL, Laravel queues, scheduler, and SSL.

## 1. Server requirements

Recommended VPS baseline:

- Ubuntu 22.04 LTS or 24.04 LTS
- PHP 8.2 or newer
- Composer 2
- MySQL 8 or MariaDB 10.6+
- Node.js 20+
- Nginx or Apache
- Supervisor for Laravel queues
- Certbot for SSL

Required PHP extensions:

```bash
sudo apt update
sudo apt install -y software-properties-common ca-certificates curl unzip git
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update
sudo apt install -y \
  php8.3 php8.3-cli php8.3-fpm php8.3-common php8.3-mysql php8.3-mbstring \
  php8.3-xml php8.3-curl php8.3-zip php8.3-bcmath php8.3-tokenizer \
  php8.3-fileinfo php8.3-gd php8.3-intl
```

Install Composer:

```bash
cd /tmp
php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');"
php composer-setup.php
sudo mv composer.phar /usr/local/bin/composer
composer --version
```

Install Node.js 20+:

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
node -v
npm -v
```

## 2. Application deployment

Set the deployment directory:

```bash
sudo mkdir -p /var/www/trial-manager
sudo chown -R $USER:www-data /var/www/trial-manager
cd /var/www/trial-manager
```

Clone or upload the repository, then enter the Laravel app folder:

```bash
git clone <your-repository-url> .
cd trial-manager
```

Install PHP dependencies:

```bash
composer install --no-dev --optimize-autoloader
```

Install and build frontend assets:

```bash
npm ci
npm run build
```

Create production environment file:

```bash
cp .env.example .env
php artisan key:generate
```

Set permissions:

```bash
sudo chown -R www-data:www-data storage bootstrap/cache
sudo chmod -R ug+rw storage bootstrap/cache
```

Run database migrations and seed the initial admin/settings data:

```bash
php artisan migrate --seed --force
```

Optimize Laravel:

```bash
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan event:cache
```

Important production notes:

- Set `APP_DEBUG=false`.
- Use a real `APP_KEY` generated by `php artisan key:generate`.
- Change `ADMIN_PASSWORD` before seeding a fresh database.
- Store WhatsApp Cloud API and Telegram Bot credentials from the admin Integrations page after login.

## 4. MySQL setup

Install MySQL:

```bash
sudo apt install -y mysql-server
sudo mysql_secure_installation
```

Create database and user:

```bash
sudo mysql
```

```sql
CREATE DATABASE trial_manager CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'trial_manager_user'@'localhost' IDENTIFIED BY 'use-a-strong-password';
GRANT ALL PRIVILEGES ON trial_manager.* TO 'trial_manager_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

Verify connection:

```bash
mysql -u trial_manager_user -p trial_manager
```

## 5. Nginx configuration

Install Nginx:

```bash
sudo apt install -y nginx
```

Create `/etc/nginx/sites-available/trial-manager`:

```nginx
server {
    listen 80;
    listen [::]:80;
    server_name your-domain.com www.your-domain.com;

    root /var/www/trial-manager/trial-manager/public;
    index index.php index.html;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    charset utf-8;
    client_max_body_size 20M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ ^/index\.php(/|$) {
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_hide_header X-Powered-By;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
```

Enable site:

```bash
sudo ln -s /etc/nginx/sites-available/trial-manager /etc/nginx/sites-enabled/trial-manager
sudo nginx -t
sudo systemctl reload nginx
```

## 6. Apache configuration

Install Apache and PHP module/FPM support:

```bash
sudo apt install -y apache2 libapache2-mod-php8.3
sudo a2enmod rewrite headers ssl
```

Create `/etc/apache2/sites-available/trial-manager.conf`:

```apache
<VirtualHost *:80>
    ServerName your-domain.com
    ServerAlias www.your-domain.com
    DocumentRoot /var/www/trial-manager/trial-manager/public

    <Directory /var/www/trial-manager/trial-manager/public>
        AllowOverride All
        Require all granted
        Options -Indexes +FollowSymLinks
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/trial-manager-error.log
    CustomLog ${APACHE_LOG_DIR}/trial-manager-access.log combined
</VirtualHost>
```

Enable site:

```bash
sudo a2ensite trial-manager.conf
sudo apache2ctl configtest
sudo systemctl reload apache2
```

Use either Nginx or Apache, not both on port 80/443.

## 7. SSL setup

Install Certbot:

```bash
sudo apt install -y certbot python3-certbot-nginx python3-certbot-apache
```

For Nginx:

```bash
sudo certbot --nginx -d your-domain.com -d www.your-domain.com
```

For Apache:

```bash
sudo certbot --apache -d your-domain.com -d www.your-domain.com
```

Verify renewal:

```bash
sudo certbot renew --dry-run
```

## 8. Laravel queue setup

Create queue tables if using database queues:

```bash
php artisan queue:table
php artisan migrate --force
```

Install Supervisor:

```bash
sudo apt install -y supervisor
```

Create `/etc/supervisor/conf.d/trial-manager-worker.conf`:

```ini
[program:trial-manager-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/trial-manager/trial-manager/artisan queue:work database --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
user=www-data
numprocs=1
redirect_stderr=true
stdout_logfile=/var/www/trial-manager/trial-manager/storage/logs/worker.log
stopwaitsecs=3600
```

Start worker:

```bash
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start trial-manager-worker:*
```

## 9. Cron setup

Add Laravel scheduler cron:

```bash
sudo crontab -u www-data -e
```

Add:

```cron
* * * * * cd /var/www/trial-manager/trial-manager && php artisan schedule:run >> /dev/null 2>&1
```

## 10. Telegram webhook setup

After deployment:

1. Login to Trial Manager.
2. Open Settings -> Integrations.
3. Enter Telegram Bot Token.
4. Enter Webhook URL:

```text
https://your-domain.com/api/telegram/webhook
```

5. Click Save Telegram Settings.
6. Click Set Webhook.
7. Click Test Bot.

## 11. WhatsApp Cloud API setup

In Meta Developer dashboard, collect:

- Permanent access token or system user token
- Phone Number ID
- Business Account ID
- Verify Token
- Test recipient number

Then:

1. Login to Trial Manager.
2. Open Settings -> Integrations.
3. Enter WhatsApp Cloud API credentials.
4. Click Save WhatsApp Settings.
5. Click Send Test Message.

## 12. Deployment health checks

Run after every deployment:

```bash
composer install --no-dev --optimize-autoloader
npm ci
npm run build
php artisan migrate --force
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan about
php artisan route:list
php artisan queue:restart
```

Check logs:

```bash
tail -f storage/logs/laravel.log
sudo supervisorctl status
sudo systemctl status nginx
sudo systemctl status php8.3-fpm
```

## 13. Rollback notes

Before deploying new code:

```bash
mysqldump -u trial_manager_user -p trial_manager > backup-$(date +%F-%H%M%S).sql
```

Rollback code with your deployment system or git:

```bash
git log --oneline
git checkout <previous-good-commit>
composer install --no-dev --optimize-autoloader
npm ci
npm run build
php artisan migrate --force
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan queue:restart
```
